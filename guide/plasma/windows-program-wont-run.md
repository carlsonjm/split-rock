## What you see

You downloaded a program from its website, as you always did on Windows, and
got a file ending in .exe or .msi, such as ZoomInstaller.exe. Opening it does
nothing, or the computer asks what to open it with.

## Why

Those files are made for Windows, and this computer runs Linux, so it can't
run them. Most programs you know have a Linux version, and many that don't
have a Linux app that does the same job. On this computer, apps come from one
place, like a phone's app store, instead of a download from each website.

## What to do

1. Open Install an app from Search, and type the program's name, such as Zoom.
2. Pick it from the list and tap Install. Apps from the system's own shelf ask for your password.
3. If it isn't there, type what it does instead, such as video calls or photo editor, and pick one of the apps that come up.
4. You can delete the .exe file from your Downloads folder. It will never be needed here.
