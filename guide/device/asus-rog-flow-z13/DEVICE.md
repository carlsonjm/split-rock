## How Jack recognises it

The maker the hardware reports is ASUSTeK COMPUTER INC., and its product name
contains "ROG Flow Z13". The exact model follows that name and is read from the
computer, not assumed.

## What it is

A 13-inch tablet with a detachable keyboard cover, which makes it a laptop when
attached. It has a touchscreen and its own power firmware, and on Windows the
maker's own software looked after both.

## What is known

- The touchscreen is an ELAN panel. On the test machine the screen is 2560 by
  1600 and is used at 175% scaling.
- The test machine runs a tablet posture service that switches between tablet
  and laptop as the cover comes and goes, and a power tool that applies the
  maker's performance presets. Neither comes with the desktop; both were added.
- Known and not yet fixed, on the test machine: sign-in froze twice as the
  power tool applied its preset, and one performance preset hung the machine in
  use. Jack offers no fix for either until one is proven.

## The maker's documentation

None is bundled yet. Without an account, Jack reads the exact model from the
computer and offers this folder. With an account, the assistant can look up the
maker's documentation for that model.
