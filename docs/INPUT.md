# Input

Every tap and key Split Rock answers, and what you see happen. Milestone 0's
window answers Choose an assistant, Sign in, Ask, Stop an answer, Decline a
change, Learn instead and Start over; the rest is the plan, and it changes when
the widget does.

| Task | Touch | Keyboard |
| --- | --- | --- |
| Open the assistant | Tap its panel button | None yet |
| Choose an assistant | Tap the assistant at the top, then one in the list | None yet |
| Sign in | Tap a way to sign in | None yet |
| Ask | Type, then tap Send | `Enter` |
| Take the tour | Tap Show me around | None yet |
| Stop an answer | Tap Send while it shows a square | `Esc` |
| Approve a change | Tap Do it on its card | None yet |
| Decline a change | Tap Not now on its card | `Esc` |
| Learn instead | Tap Show me how instead on its card | None yet |
| Undo a past change | Tap a change in the notebook, then Undo | None yet |
| Keep an answer | Tap Keep this under it | None yet |
| Forget a note | Tap Forget on the note | None yet |
| Start over | Tap New question | None yet |

## Open the assistant

| Input | What happens |
| --- | --- |
| Tap or click its panel button | The assistant's window opens above the panel. A second tap closes it. |

## Choose an assistant

| Input | What happens |
| --- | --- |
| Tap or click the assistant at the top, then one in the list | That assistant starts. Choosing another ends the conversation, which is not saved. |

## Sign in

| Input | What happens |
| --- | --- |
| Tap or click a way to sign in | The assistant opens its own sign-in page, usually in the browser. Jack waits, and never sees the password. Cancel stops waiting. |

## Ask

| Input | What happens |
| --- | --- |
| Type, then tap or click Send | The answer arrives under the field: one short line, then steps. |
| `Enter` in the field | The same as Send. |

## Take the tour

| Input | What happens |
| --- | --- |
| Tap or click Show me around, with Jack's guide chosen | The first tour opens: what it shows, then its steps. A desktop's own tours come first. |
| Tap or click Next | The next tour opens, until the last. |

## Stop an answer

| Input | What happens |
| --- | --- |
| Tap or click Send while it shows a square | The assistant stops; what it said so far stays. |
| `Esc` in the field | The same. |

## Approve a change

| Input | What happens |
| --- | --- |
| Tap or click Do it on its card | Its undo is recorded first, then only that change is made. In Milestone 0, Do it is unavailable: every change was already refused. |

## Decline a change

| Input | What happens |
| --- | --- |
| Tap or click Not now on its card | Nothing changes, and the card is set aside. The answer keeps a Do it button that brings it back. |
| `Esc` while the card shows | The same as Not now. |

## Learn instead

| Input | What happens |
| --- | --- |
| Tap or click Show me how instead on its card | Nothing changes. The steps to make the change yourself appear, one at a time. |

## Undo a past change

| Input | What happens |
| --- | --- |
| Tap or click a change in the notebook, then Undo | A card shows what putting it back will change. Nothing happens until you tap Do it. |

## Keep an answer

| Input | What happens |
| --- | --- |
| Tap or click Keep this under it | The answer becomes a note, filed by topic in the notebook. |

## Forget a note

| Input | What happens |
| --- | --- |
| Tap or click Forget on the note | The note moves to the desktop's trash, where it can be restored. |

## Start over

| Input | What happens |
| --- | --- |
| Tap or click New question | The conversation ends and is not saved. Kept notes and the notebook stay. |
