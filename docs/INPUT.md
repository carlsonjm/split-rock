# Input

Every tap and key Split Rock answers, and what you see happen. None is built
yet; this map is the plan, and it changes when the widget does.

| Task | Touch | Keyboard |
| --- | --- | --- |
| Open the assistant | Tap its panel button | None yet |
| Approve a change | Tap Do it on its card | None yet |
| Decline a change | Tap Not now on its card | None yet |
| Learn instead | Tap Show me how instead on its card | None yet |
| Undo a past change | Tap a change in the notebook, then Undo | None yet |
| Keep an answer | Tap Keep this under it | None yet |
| Forget a note | Tap Forget on the note | None yet |
| Start over | Tap New question | None yet |

## Open the assistant

| Input | What happens |
| --- | --- |
| Tap or click its panel button | The assistant's window opens above the panel. A second tap closes it. |

## Approve a change

| Input | What happens |
| --- | --- |
| Tap or click Do it on its card | Its undo is recorded first, then only that change is made. |

## Decline a change

| Input | What happens |
| --- | --- |
| Tap or click Not now on its card | Nothing changes, and the card is set aside. |

## Learn instead

| Input | What happens |
| --- | --- |
| Tap or click Show me how instead on its card | Nothing changes. The steps to make the change yourself appear, one at a time. |

## Undo a past change

| Input | What happens |
| --- | --- |
| Tap or click a change in the notebook, then Undo | A card shows what putting it back will change. Nothing happens until you tap Do it. |

## Keep an answer

| Input | What happens |
| --- | --- |
| Tap or click Keep this under it | The answer becomes a note, filed by topic in the notebook. |

## Forget a note

| Input | What happens |
| --- | --- |
| Tap or click Forget on the note | The note moves to the desktop's trash, where it can be restored. |

## Start over

| Input | What happens |
| --- | --- |
| Tap or click New question | The conversation ends and is not saved. Kept notes and the notebook stay. |
